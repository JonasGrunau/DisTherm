# DisTitten

## Purpose
A recreation of Output Thermal 1.2.1 (multistage distortion, VST3 / AU, JUCE 8), measured from Thermal's output only (method and findings in `docs/thermal-re/`). Input gain → three stages (each: LR4 band split, distortion with 34 shapes on the band at 2x oversampling, one of nine effects, mid/side width, gain, then the summed tone shelves) → FX 1 → FX 2 → master compressor → output bus (HP/LP on the wet, dry/wet with the delayed dry, v^(5/7) law, output gain). Two drawable envelopes and two macros modulate any parameter (Thermal's ModAmount / ModBiPolar / DepthModRange routing, in the normalised domain). 446 parameters, every range, taper and default Thermal's (`src/core/model/Params.h`); Thermal's presets and states load directly. The editor copies Thermal's layout control for control (`src/ui/Layout.h`) in the house style: an XY page (pad, macros) and an edit page (band strip, stage tabs, distortion / effect, width / tone, two mod panels, XY / EFFECTS / MASTER). Invariants: the engine output equals Thermal's to −92 dB or lower per mechanism; the chain with everything off is bit exact apart from its 93-sample delay, which is reported as latency (Thermal reports 0).

## For AI Agents

### Working In This Directory
- Core loop (seconds): `cmake -B build-core -G Ninja -DCMAKE_BUILD_TYPE=Release -DDISTITTEN_BUILD_PLUGIN=OFF && cmake --build build-core && ./build-core/distitten_tests`
- Full plugin: `cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release && cmake --build build` (installs into `~/Library/Audio/Plug-Ins`). A local JUCE: `-DFETCHCONTENT_SOURCE_DIR_JUCE=...`.
- Never include JUCE from `src/core`. New `.cpp` files go into `CMakeLists.txt` by hand (core sources in `add_library`, plugin/UI sources in `DISTITTEN_UI_SOURCES`, tests in `add_executable(distitten_tests ...)`).
- Audio thread: no allocation or locks in `processBlock` / `dt::Engine::process`. Buffers are sized in `prepare`.
- Parameters are copied once per host block (`readParams`); modulation state arrives through `ModStateChannel::fetch` (no locks; a torn read keeps the previous copy). Thermal's LOW/HIGH coupling is computed on the audio thread and written back to the parameters by the processor's timer on the message thread, never from `processBlock`.
- Fidelity first: a change to `src/core` must keep matching Thermal. Behaviours that look odd (per-host-block updates, float32 accumulators, FMA off in parameter mapping, flanger/phaser restarting from defaults) are measured Thermal behaviour; check `docs/thermal-re/` before "fixing" one. Deliberate deviations are listed in README ("On purpose different from Thermal").
- JUCE 8 API: text widths via `theme::textWidth` (no `Font::getStringWidthFloat`); `juce::String (x, 0)` prints all decimals, format numbers through the theme/format helpers.
- Don't edit `build*/` or `.cache/`.

### Testing Requirements
- After core changes: `./build-core/distitten_tests` must pass (latency 93, bit-exact isolated chain with stages on and off, the dry/wet law, every effect in every slot and every distortion shape finite, the modulation depth formula). Fidelity against Thermal itself is measured with the black-box rig in `docs/thermal-re/method.md` (not in the repo; needs Thermal installed).
- After UI changes: build `distitten_snapshot`, render the states (`main edit busy stagefx comp stage3 assign`) and read the PNGs; compare positions against Thermal (`src/ui/Layout.h` holds its measured rectangles). If the look changed, re-render `docs/screenshot.png`: `SNAP_PARAMS="s1_lo=640,s1_hi=1970,s2_lo=30,s2_hi=640,s3_lo=1970,s3_hi=22000,s1_split=1,s2_split=1,s3_split=1" distitten_snapshot docs busy`, then rename.
- Before a release: `auval -v aufx DsTt Jgru` (instrument: `aumu`) and pluginval at strictness 5 on both formats.

### Common Patterns
- Namespaces: `dt` (core), `dt::dsp` (primitives), `theme` (UI tokens and helpers). Plugin/UI classes are global.
- JUCE-style formatting: space before call parens `foo (x)`, 4-space indent, braces on their own line.
- Layout: Thermal's, exactly (user's brief); every rectangle comes from `src/ui/Layout.h`. Look: the house style, never Thermal's (night sheet `#131211`, bone ink `#ece7db`, one accent magenta `#ff71bb` meaning the heat: transfer curve, drive / shape rings, the band a stage works on, the pad's glow; no per-source colours, gradients, shadows or glow; corner radius 2 px; IBM Plex Sans Condensed labels, Plex Mono numbers).

## Dependencies
- JUCE 8.0.15 (AGPLv3), Catch2 v3.7.1, C++20, CMake >= 3.24, macOS deployment target 11.0
- IBM Plex (OFL), bundled in `resources/fonts`
- Thermal factory presets are read from the user's own installation (`/Library/Application Support/Output/Thermal/Presets`); never copy them, or any Thermal audio, into the repo
